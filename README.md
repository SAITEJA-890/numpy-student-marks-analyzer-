# NumPy Student Marks Analyzer 📊

A beginner-friendly Python project using NumPy to analyze student marks.

## 📌 Project Description

This project takes marks of a student in different subjects and performs basic statistical analysis using NumPy.

## 🚀 Features

- Calculate total marks
- Calculate average marks
- Find the highest mark
- Find the lowest mark
- Find the subject with the highest mark
- Find marks above the average
- Calculate standard deviation
- Display student performance

## 🛠️ Technologies Used

- Python
- NumPy

## 📚 NumPy Concepts Used

- NumPy Arrays
- np.sum()
- np.mean()
- np.max()
- np.min()
- np.std()
- np.argmax()
- Boolean Filtering

## 📊 Subjects

The project analyzes marks for:


- Math's
- Physics
- Social
